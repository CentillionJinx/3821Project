Deterministic Verification

A decision problem X ∈ NP if there exists a polynomial p and deterministic polynomial-time verifier algorithm V such that:

x ∈ X ⇔ ∃ w ∈ {0, 1}p(|x|) : V(x, w) = ACCEPT

The witness w encodes the player's chosen carpet subcollection, blob coordinates, or army deployment schedule.

Reduction Y ≤p X

The Reduction Paradigm

Hardness is proved by transforming instances I of a known NP-complete problem Y into puzzle instances f(I) in deterministic O(|I|c) time:

Completeness: I ∈ YES ⇒ f(I) ∈ YES
Soundness: f(I) ∈ YES ⇒ I ∈ YES

Variable gadgets isolate binary choices (True / False); clause and barrier gadgets enforce logical constraints through geometry.

Complexity O(2n) vs O(nk)

The Intractability Gap

The defining duality of NP-complete puzzle design: finding an arrangement of pieces requires searching an exponential solution space, yet verification executes instantaneously:

• Search Space: |{0,1}|S|| = 2|S| → Intractable
• Verifier Time: O(NM + |B|·|S|) → Sub-millisecond

“Carpets” Floor O(|B|·|S| + NM)

Multiplicity & Unique Cover Grid

Given grid G = N × M and family C of carpets, select subcollection B ⊆ C satisfying exact target multiplicities v(t) and the unique cover no-waste constraint.

1. Full Cover: ∪S ∈ B S = G
2. Multiplicity: multM(t) = v(t) ∀ t
3. Unique Cover: ∀ Q ∈ B, ∃ t ∈ Q : mult(t) = 1
Verifier Pipeline: Computes multiplicity array in O(|B|·|S|) steps, checks target parity/equality in O(NM), and verifies unique witness existence in O(|B|·|S|).
“Microbes” (Hearts) O(|B|²·|T|)

Grid Polyomino Organ Invariant

Discrete N × M tile grid G. Blobs are connected grid tiles (polyominoes) A = (T(A), O(A)) with vital organ tiles O(A) (♥). Polyominoes may overlap on ordinary cells, but vital organ tiles cannot be occupied by ANY tile of another blob.

Grid Invariant: ∀ A ≠ B ∈ B :
O(A) ∩ T(B) = ∅ ∧ O(B) ∩ T(A) = ∅
Grid Quota: |∪ T(A)| ≥ K (Tile Coverage)
Grid Verifier Pipeline: Checks pairwise non-intersection of vital organ cell coordinates against occupied tile masks in O(|B|²·|T|) steps. Connected polyomino arms act as signal wires.
“Quell Insurgency” O(m(|V| + |E|))

Contagion Dynamical System

Discrete dynamical process on graph G = (V, E). Insurgents (w=2) spread +1 to neighbours daily. Dictator army deploys to 1 vertex/day (w=-1, quells adjacent w≤1 → 0). Total weight ≤ n in m days.

Phase 1: wv ← min(2, wv + 1) via insurgents
Phase 2: wα(d) = -1; ∀ u ∼ α(d), wu≤1 → 0
Decision: ∑v: wv>0 wv ≤ n after m days
Reduction Heritage: Generalizes the Firefighter Problem (Finbow et al. 2007, NP-complete on trees of max degree 3). Simulating m days takes O(m(|V| + |E|)).

Gadget Reduction Architectures

Parks Problem (Star Battle) ← 3-SAT: 2-wide alternating cycle corridors yield exactly 2 maximal independent sets (True/False). 8-neighbour non-adjacency enforces clause deadlocks.
Akari (Light Up) ← Circuit-SAT: Orthogonal light beams simulate binary signal wires. Numbered wall blocks (0..4) and ray intersections construct NOT, AND, and OR logic gates.
Held-Karp Dynamic Programming (TSP): Exact subproblem recurrence C(S, v) = min [C(S\{v}, u) + dist(u,v)] solves TSP in O(n²·2n), bypassing O(n!) brute-force.
