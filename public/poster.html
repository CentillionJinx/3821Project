Theory I P ⊆ NP ⊆ NP-C

Complexity Classes & Verification

A decision problem X ∈ NP if an affirmative answer has a polynomial-length certificate (witness w) that a deterministic Turing machine verifies in time O(|s|^c).

Verifier V(x, w) → {ACCEPT, REJECT} in poly(|x|)

While finding solutions requires exponential search across 2n assignments under P ≠ NP, verifying proposed certificates on our platform takes sub-millisecond execution.

Certificate verification is deterministic
Theory II 3-SAT ≤p Puzzle

Polynomial Gadget Reductions

To prove our original puzzles are NP-complete, we construct deterministic polynomial reductions f: Y → X from known NP-complete problems (3-SAT, Firefighter, X3C) satisfying:

I ∈ YES(Y) ⇔ f(I) ∈ YES(X)

Both directions must hold: Completeness (satisfying assignment → valid puzzle solution) and Soundness (valid puzzle solution → satisfying assignment).

Size |f(I)| is strictly bounded by poly(|I|)

Candidate 1 • “Carpets” O(|B|·|S| + NM)

Floor Repair Multiplicity Grid

Given grid G and carpet set C, select B ⊆ C covering G such that each damaged tile's multiplicity matches engineer target v(t), and each carpet covers at least one tile uniquely (no waste).

1. ∪S ∈ B S = G (Full Coverage)
2. multM(t) = v(t) (Target Overlap)
3. ∃ t ∈ Q: mult(t)=1 (Unique Cover)
Variations: Toroidal Ringworld • Walls
Candidate 2 • “Microbes” O(|B|²·|T|)

Vital Organ Non-Overlap

Blobs A = (T(A), O(A)) may overlap on normal tissue, but vital organs O(A) (marked with ♥) cannot overlap with ANY part of another blob B. Satisfies target nutrient coverage.

∀ A ≠ B ∈ B:
O(A) ∩ T(B) = ∅
∪ T(A) ≥ K (Coverage Quota)
Variations: Tetris Stacking • Toxic Zones
Candidate 3 • “Insurgency” Firefighter Gen

Contagion vs Dictator Army

Hex board with initial w=2 insurgent nodes. Insurgents spread +1 to neighbours each day. Army deploys to 1 node/day (w=-1, quells adjacent w≤1 to 0). Win if total unrest ≤ n after m days.

Phase 1: Insurgents w←min(2, w+1)
Phase 2: Army w←-1 & quells adj
Goal: ∑ max(0, wv) ≤ n in m days
Theoretical Base: Finbow et al. (2007) Firefighter
Citation Channel 6 Researched Topics

Researched Gadget Reductions

1. Parks Problem (Star Battle) ← 3-SAT

Alternating cycle tracks encode boolean truth. 8-neighbourhood non-adjacency creates clause deadlock rooms that block star placement when all 3 literals evaluate to False.

2. Akari (Light Up) ← Circuit-SAT

Light ray corridors act as signal wires. Numbered wall blocks (0..4) and beam occlusion simulate logic gates (NOT, AND, OR), clamping formula satisfiability.

3. The Held-Karp Algorithm for TSP

Dynamic programming recurrence C(S, v) = min [C(S\{v}, u) + dist(u,v)] reduces factorial brute-force O(n!) to O(n² · 2n).

4. Hedonic Games ← Exact Cover by 3-Sets (RX3C)

Cooperative team coalition formation where stable player partitions exist iff universe U has an exact 3-cover.
